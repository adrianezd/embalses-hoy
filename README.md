# Embalses de España hoy

Reserva de agua de España por cuencas y embalses, comparada con hace un año y con la media de diez años.

Sitio: https://adrianezd.github.io/embalses-hoy/

`datos.json` lo regenera cada martes la Action de `.github/workflows` con `actualizar.py` (boletín hidrológico del MITECO).
